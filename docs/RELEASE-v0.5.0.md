# 临绘 0.5.0：有效视野收缩与统一边界编辑

## 有效视野与渐变过渡区

旧版把与外框连通、RGB 三通道都不超过 12 的区域视作黑色填充，不能很好地处理渐变黑边。

新版使用径向亮度剖面、自适应亮度阈值、角向中值稳健处理，再向内收缩的传统图像处理组合，不使用 AI。参考亮度来自中心区域，默认剔除阈值为参考/局部亮度的 35%，并设最低亮度阈值 18；不再要求像素接近纯黑。默认再向内收缩 4 个原图像素。

“绘制设置”提供：

- 视野向内收缩：0-30 原图像素。
- 过渡区剔除强度：15%-70%，提高通常会进一步排除暗淡过渡区。
- 吸附开关。绘制多边形或重画时，青色虚线显示当前检测视野；只在光标距离边界 10 个屏幕像素内吸附，避免远距离拉动采点。

每张图加载时计算一次，拖动画笔不会重新计算整个视野。轮廓检测最多使用 512 边长缩略图；高分辨率有映射和采样误差。偏心、非星形视野、多个独立视野、严重遮挡或极暗画面可能检测不准，需要人工检查或关闭吸附。这是工程组合改进，未声称学术首创。

本机 1920×1080 合成渐变 PNG，20 次检测包含文件解码、缩略和算法，耗时中位数约 21.55 ms，95 分位约 22.42 ms；不是所有设备或实际病例的性能保证。

## 所有轮廓修改统一到“选择编辑”

移除补画 / 合并 / 扣除下拉框，移除“折线切分”开关与记住保留选择选项。

1. 按 E 进入选择编辑。
2. 单击节点即可拖动。单击边线可产生可拖动节点。
3. 双击已有完整多边形的节点或边线，激活重画起点；不需要 Ctrl 或额外模式。
4. 逐点点击，或 Shift＋左键拖动，绘制新边界。
5. 新路径接回原轮廓任意边界时自动结束，按蓝色 / 橙色预览弹窗选择保留区域；每次都会询问。路径可以在内部切分，也可向外扩展。候选区域重叠时不提供“保留两块”，避免重复覆盖。
6. Esc 取消；Ctrl＋Z 撤回草稿点。完成后可以撤销恢复原轮廓。

新边界保存实际接受的每个采样点，不进行多项式拟合或标注轮廓简化。视野边界检测与标注顶点存储是两件事。

## 新建多边形闭合

按用户确认保留“接近起点自动闭合”，也可右键、Enter、点击起点完成。编辑重画时右键终点仍需落在原边界，不能把一条悬空路径强行当作修改后的区域。

## 快捷键

工具栏直接显示：E 选择编辑、A 多边形、B 矩形框、P 点、L 线、G 涂鸦、C 圆形、H 平移。

新增 Tab 在“选择编辑”和“多边形”之间切换，仅画布有焦点时生效，不占用输入框的 Tab。未完成路径切换工具时仍需决定完成、放弃或取消，避免丢失草稿。

## 验证与版本范围

保留已有保存与格式测试，替换已删除运算入口的过时交互测试，增加双击边线重画、单击拖点、接回自动弹窗、向外扩展、右键闭合、Tab 切换、渐变边缘收缩与暗色窄条干扰测试。旧版补画/扣除草稿不会静默当作新区域恢复，原草稿文件保留。

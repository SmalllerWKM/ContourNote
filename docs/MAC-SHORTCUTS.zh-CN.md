# Mac v0.6.0 快捷键

先单击画布，再使用绘图快捷键；在输入框内复制粘贴操作文字。

| 操作 | Mac |
|---|---|
| 选择编辑 / 多边形 | E / A |
| 框 / 点 / 折线 / 涂鸦 / 圆 / 小手 | B / P / L / G / C / H |
| 连续采点 | Shift＋左键拖动 |
| 平移 / 缩放 | 空格＋左键或中键拖动 / 滚轮 |
| 完成 / 取消 | 右键或 Enter / Esc |
| 复制选中标注 / 粘贴 / 保存 | Command＋C / V / S；也支持物理 Control＋C / V / S |
| 撤销 / 重做 | Command＋Z / Command＋Shift＋Z |
| 编辑与多边形切换 | Tab（画布有焦点） |
| 上一帧 / 下一帧 | W / D，或左右方向键 |
| 适应窗口 / 原始大小 | F / 数字 1 |
| 放映开始暂停 / 全屏 | F5 / F11；被系统占用时尝试 Fn＋F5 / Fn＋F11 |

复制标注时先用 E 选中标注，再按 Command＋C；切换到相同尺寸图像后按 Command＋V。Windows 使用 Ctrl＋C/V/S。其他 Mac Ctrl 组合通常映射为 Command，不表示全部支持物理 Control。

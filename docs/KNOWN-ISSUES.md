# 已知问题与使用边界（0.5.2）

最后整理：2026-11-05。以下为仍需处理的问题，不因添加更新日志而视为已修复。

## 项目与保存

- **跨项目保存目录隔离：** 指定独立 JSON 保存目录后，再打开另一个项目，同名且同尺寸图片可能载入前一项目的标注并写回同一 JSON。问题修复前，切换项目先关闭并重新启动应用，避免沿用上一项目自定义目录；每个项目使用独立保存目录，并检查 JSON 路径与标注内容。
- **Windows 跨盘保存：** 图片与 JSON 在不同盘符时，相对路径生成存在异常；尚未原生验证及修复。Windows 试用时暂将图片与标注放在同一盘，并核对保存状态。
- .json.bak 只保留上一份落盘版本，自动保存不是无限历史或独立备份。

## 平台

- Windows x64 仅完成打包、短路径、ZIP 完整性与静态依赖审计，尚未实机启动和交互验收。
- Mac 包为 Apple 芯片 arm64，ad-hoc 签名，未进行 Apple 开发者签名/公证。
- 没有 Intel Mac、Windows ARM64 或 Linux 的独立发行包。

## 标注与格式

- 有效视野是启发式检测，极暗、遮挡、偏心、非星形或多独立视野可能检测错误。先检查青色虚线，必要时调整或关闭吸附。
- 落点投影不等于对整个形状面积进行裁剪，已有轮廓、圆形和矩形仍需检查。
- 0.5.2 删除记录功能，旧 clinical 数据仅原样保留，不控制当前校验和 Mask。没有完整区域时 Mask 为未知 255，不自动把旧“无目标”记录当全背景。
- 类别编号取决于本次数据集名称集合；重叠区域的语义 Mask 按后绘制类别覆盖，COCO 可以保留多个实例。
- 75 项测试和合成性能检查不等于临床验证、医生效率评估或所有真实大型数据的性能验收。

反馈问题时请附软件版本、系统/架构、重现步骤及脱敏后的错误信息。请勿公开上传病例、身份信息或未获授权的数据。

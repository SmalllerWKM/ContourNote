# 临绘 0.4.1：补画 / 合并 / 扣除工作流修复

## 复现的问题

旧版在“选择编辑”模式选择“补画 / 合并”或“扣除选区”，下拉框只改变运算参数，不会激活多边形工具；随后鼠标仍然操作原轮廓，根本没有产生可闭合的新路径。另外，Ctrl 点击原轮廓节点可能转入局部切分，右键和 Enter 因此无法完成区域运算。选择弱提示或没有选中原区域时，旧版往往到最后才拒绝运算，提示仅停留在短暂状态栏中。

旧测试直接给 canvas.draft 填入坐标再调用 finish()，只证明几何算法能运行，没有覆盖真实的工具切换和绘制流程。

## 修复后的用法

1. 按 E 选中原来的完整区域；也可以在右侧列表选择。合并多个区域时选择同一类别。
2. 选择“补画 / 合并”或“扣除选区”，软件自动切换到多边形工具，保留原选区。画布上方显示操作说明。
3. 逐点点击或按 Shift＋左键拖动画出一个闭合区域。补画时让新区域与旧区域重叠；连接两个区域时让新区域与两边都重叠。
4. 接近新路径起点可自动闭合，也可点击起点、右键或按 Enter 完成。运算以闭合区域进行，不要求新路径终点落在旧区域边界上。
5. 自动闭合后立即 Ctrl＋Z（Mac 对应 Command＋Z），恢复草稿和原选区，可以继续修改后再次完成。

“折线切分”是另一种编辑方式：起点在原节点、终点在原边界；不要把切分方式与闭合区域运算混用。

弱框、点、线等提示没有精确分割语义，因此会在进入区域运算时明确拒绝；软件不会把弱框偷偷转成完整区域。草稿如果自交或几何无效，会保留当前路径，并在画布上方持续显示错误和撤回方法。

## 数据保留

单区域补画或扣除保留 description、flags 和 extra。多区域合并若来源元数据不同，在 contour_note_sources 扩展中保留来源记录，避免静默丢失。没有用拟合或简化减少采集顶点。

## 验证与限制

新增 12 个实际鼠标/键盘工作流测试，覆盖补画与扣除的 Enter、右键、自动闭合、Shift 连续采点，两个区域合并、Ctrl 冲突、弱提示/空选区拒绝，以及自动闭合撤销后再次完成。修复前“从编辑进入区域运算”的测试失败，修复后通过。

此次仅针对区域运算工作流修复。0.4.0 审查发现的跨项目保存目录隔离、Windows 跨盘保存、视野检测误吸附等其他问题尚未在本次修复；重要项目仍需备份并审慎试用。Windows 包仍未进行实机运行验收。

# ContourNote v0.6.0 · 减少弹窗与直接编辑

本地构建日期：2026-11-06。

- 复制上一帧：取消常规确认/完成弹窗，画布底栏显示复制和保存状态。
- 连续复制后续 X 帧：输入框默认 1，不再弹出帧数输入框、确认框或完成框；范围超出时底栏提示并停止。
- 将复制来源写入 Labelme JSON 扩展字段 contour_note_copy，目标帧重新打开仍显示“本帧标注来自于前帧的复制，请仔细检查”。不新增人员审核表单。
- 局部重画：点击原边界完成后默认保留大块，灰色小块可双击改选，取消区域选择弹窗；修改与撤销均同步自动保存。灰色候选不进入导出。
- 对齐连续采点终点与原边界，修复像素取整导致的退化闭合。
- Mac 支持 Command/Control 的 C、V、S；Windows 支持 Ctrl+C/V/S；输入框保留文字复制粘贴。
- 图片放映速度、循环、开始/暂停直接显示在顶部。
- 保留保存冲突、未保存修改和未完成草稿等数据保护提示。复制仍为坐标复用，不自动跟踪运动。
- 许可证、第三方归属资料和库替换说明随包保留；对应依赖版本及源码沿用许可证修订版提供的材料。

Mac 原生保存/导出/界面与静态打包检查另见验证说明；Windows 仍须实机验收。

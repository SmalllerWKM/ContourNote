# ContourNote v0.4.1 · 区域运算真实操作流程修复

本地完成/构建日期：2026-11-03。

## 修复

- 选择补画/合并或扣除时自动切换到多边形工具，保留原选区。
- 修复 Ctrl 点击误进入局部切分的冲突；空选区、弱提示和类别不一致提前提示。
- 画布上方持续显示操作说明或失败原因；支持自动闭合、右键、Enter、Shift 采点完成运算。
- 修复自动闭合撤销后丢失原选区、无法再次完成运算。
- 单来源区域运算保留 description、flags、extra；多来源元数据冲突时以 contour_note_sources 保留来源。

## 验证与后续变化

- 新增 12 项真实鼠标/键盘工作流测试，总计 73 项通过；Mac 独立应用验证通过。
- 这些区域运算入口随后在 0.5.0 被移除，当前 0.5.2 使用双击边界重画。

## 发行状态与限制

- macOS Apple 芯片包已进行本机独立应用验证。
- Windows x64 包已进行静态包/依赖检查，尚未 Windows 实机验收。
- 已知跨项目保存目录隔离和跨盘保存问题尚未修复，不应将此版本描述为已完成稳定性验收。

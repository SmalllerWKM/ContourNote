# ContourNote v0.5.2-licensefix1 · 许可证、对应源码与双角色流程说明

应用版本仍为 0.5.2。本次为许可证告知、打包和文档修订；推荐使用带
`licensefix1` 的新包。本地整理日期：2026-11-05。

## 本次修订

- 补齐 LGPLv3 / GPLv3 等许可证全文、第三方组件与版权归属资料；上游原始路径见许可证索引。
- 安装包提供“开源许可”入口，明确 LGPL 库的修改、替换及重新链接权利。
- 免费提供 Qt 6.12.0、PySide6 / Shiboken6 6.12.0、GEOS 3.14.1 对应源码附件，附官方来源、哈希及替换/构建说明。
- 排除未使用的 PDF、虚拟键盘、QML / Quick 等 Qt 组件，减少无关依赖。
- README 突出缩放平移、连续采点、弱标注、局部修正、可见帧操作及实时保存等面向标注习惯的功能。
- 明确双角色操作流程：标注者完成初标，审查修改者通过 E 选择编辑在原结果上移动节点或局部重画，不必删除整个标注。
- 不新增账号、权限、审核表单或初标/复核数据差异版本系统；如需分别留存两套数据，交接前复制完整项目到独立工作目录。

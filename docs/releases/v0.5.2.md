# ContourNote v0.5.2 · 手动确认重画、可关闭提示、移除记录页面

本地完成/构建日期：2026-11-05。

## 新增与调整

- 黄色提示条增加“关闭提示”，关闭后保留当前草稿；完成或取消草稿也清除提示。
- 已有轮廓重画仅在点击原边界后弹出保留选择；悬停、靠近、经过、Shift 拖动均不自动确认。右键点击原边界也可确认。
- 保留新建多边形的接近起点自动闭合、右键与 Enter 完成。

## 移除与兼容性变化

- 删除“记录”页面及图像判断、置信度、审核、质量、识别困难和备注控件。
- 停止自动生成 clinical 字段，复制/传播不再生成审核与来源记录。旧文件已有 clinical 扩展原样保留，但不再参与质检、完成勾选和 Mask 判定。
- 没有完整区域的图像输出未知值 255；旧 clinical 中的“无目标”不再自动导出全背景 Mask。依赖旧记录生产负样本的流程需要另行明确标签。

## 验证

- 75 项自动化测试通过；Mac 独立应用原生启动、JSON 保存、COCO 导出和窗口渲染通过。

## 发行状态与限制

- macOS Apple 芯片包已进行本机独立应用验证。
- Windows x64 包已进行静态包/依赖检查，尚未 Windows 实机验收。
- 已知跨项目保存目录隔离和跨盘保存问题尚未修复，不应将此版本描述为已完成稳定性验收。

# ContourNote v0.3.0 · 自适应工作区、可见帧操作与双平台运行包

本地完成/构建日期：2026-11-02。

## 新增与调整

- 默认最大化；画布在适应模式下随窗口/分栏调整，手动缩放保留比例；支持 F11。
- 左侧中文工具使用横排图标和文字，按实际尺寸调整，减少显示不全。
- 上一帧、下一帧、复制上一帧、向后 N 帧传播和仅复用弱标注常显。
- 连续采点改为 Shift＋鼠标左键拖动；只按 Shift 移动不再落点。
- 新增 0.1-120 秒/张的图片放映、开始/暂停、循环与 F5；编辑或存在未完成/未保存/冲突时暂停。
- 显示线宽可调 0.5-8 px 并随项目保存；显示设置不改变 Mask。
- 已有有效标注的图片名前显示勾选，空 JSON 不打勾。
- 提供 macOS arm64 独立应用与 Windows x64 内置运行环境便携包。

## 验证与资料

- 52 项测试通过；Mac 独立包启动、保存、导出和窗口渲染验证通过；Windows 为静态打包/依赖检查。
- 同日整理中英文 README、真实合成界面截图和双语示意图，另有 0.3.0 文档包；这些资料整理没有增加软件版本号。

# ContourNote v1.0.0 · 首个正式版

本地构建日期：2026-11-06。

将最新版 0.6.0 的现有功能确定为首个正式版本，统一应用内部版本、Mac 应用信息、Windows 构建清单、下载包及文档为 1.0.0。本次不改变标注算法或编辑逻辑。

## 主要功能

- 多边形、框、点、线、涂鸦等人工标注；不预设前景类别，没有 AI 模型。
- 滚轮缩放、小手平移、Shift＋鼠标左键连续逐点采样；新建多边形接近起点、右键或 Enter 闭合。
- 标注者建立初标；审查修改者通过选择编辑拖动节点，或双击原边界后局部重画，再点击原边界结束。默认保留大块，灰色小块双击改选，无需选择弹窗。
- 有效视野边界感知、可调内收和无效区落点吸附；实际接受顶点逐点保存。
- 复制上一帧、连续复制后续 X 帧（默认 1）；底栏显示状态，目标 JSON 保留复制来源并提示人工检查。
- 放映速度、循环、开始/暂停常显；Mac Command/Control+C/V/S，Windows Ctrl+C/V/S。
- 自动保存 Labelme 兼容 JSON，显示保存状态和文件修改时间，支持 COCO、语义 Mask 与弱提示 Mask 导出。
- MIT 应用源码；第三方许可、对应源码来源和库替换说明随包提供，历次更新日志完整保留。

## 验证范围与已知限制

正式版是本次发布状态，不表示新增临床验证或完成 Windows 实机验收。Windows 仍仅有压缩路径、应用代码一致性与依赖静态检查；Mac 包为 Apple 芯片 arm64、ad-hoc 签名，未做 Apple 开发者签名或公证。

跨项目复用自定义 JSON 保存目录及 Windows 跨盘保存仍有已知限制，详见 [已知问题](../KNOWN-ISSUES.md) 和 [验证记录](../VALIDATION.md)。本次版本升级不宣称修复这些问题。复制只复用坐标，需逐帧检查。对应依赖版本未变，沿用许可证修订版提供的第三方源码附件。

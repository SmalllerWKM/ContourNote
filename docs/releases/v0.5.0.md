# ContourNote v0.5.0 · 渐变有效视野与统一边界编辑

本地完成/构建日期：2026-11-05。

## 新增与优化

- 以径向亮度剖面、自适应阈值、角向中值处理和内收替代纯近黑连通检测，处理渐变无效区。
- 默认剔除强度 35%，最低亮度阈值 18，额外内收 4 原图像素；内收可调 0-30 px，强度可调 15%-70%。
- 视野检测结果在切图时计算并复用，青色虚线供人工检查；本版只在距边缘 10 屏幕像素内吸附。
- 选择编辑中单击节点/边线拖动，双击节点/边线开始重画。接回原轮廓后按蓝、橙预览选择保留区域。
- 新增画布内 Tab 切换选择编辑与多边形；工具旁显示 E/A/B/P/L/G/C/H。
- 保留新建多边形自动闭合，支持右键、Enter 完成；减轻采点时同步整份 JSON 状态比较的开销。

## 移除与行为变化

- 移除补画/合并/扣除下拉框、“折线切分”开关和记住保留选择选项，修改已有轮廓统一进入选择编辑。
- 旧版补画/扣除草稿不会静默当作新区域恢复，原草稿文件保留。
- 本版重画仍可能因接近原边界自动触发弹窗；此行为在 0.5.2 改为点击确认。

## 验证

- 64 项测试通过；Mac 独立运行验证通过。测试数量减少包含已删除功能的旧交互用例退役，不代表相同测试集合中的结果倒退。
- 1920×1080 合成渐变 PNG 检测 20 次，含解码与缩略，中位 21.55 ms、95 分位 22.42 ms。不是实际病例或所有设备的延迟保证。

## 发行状态与限制

- macOS Apple 芯片包已进行本机独立应用验证。
- Windows x64 包已进行静态包/依赖检查，尚未 Windows 实机验收。
- 已知跨项目保存目录隔离和跨盘保存问题尚未修复，不应将此版本描述为已完成稳定性验收。

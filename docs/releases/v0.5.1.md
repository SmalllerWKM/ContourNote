# ContourNote v0.5.1 · 无效视野落点投影与重画闭合修复

本地完成/构建日期：2026-11-05。

## 修复

- 开启吸附且视野识别成功时，视野外落点无论距离多远都投影到最近边线；支持多边形、点、线、涂鸦和编辑节点。
- 由最近离散边界点改为最近边界线段投影；有效区内靠近边缘仍可吸附。此约束不等于对圆形、矩形或旧形状的全部面积裁剪。
- 取消重画必须至少有一个中间点的限制，允许从起点直接连接另一处原边界。
- 终点命中容差调整到 12 屏幕像素；原轮廓命中优先于视野吸附。
- 对沿原边线重复、自交、零面积等退化路径补充检查，保留原标注和草稿并解释失败原因。
- 新建多边形按投影后坐标判断接近起点，修复看起来接回但不闭合的情况。

## 验证

- 71 项测试通过；Mac 独立应用启动、保存、导出和渲染通过。

## 发行状态与限制

- macOS Apple 芯片包已进行本机独立应用验证。
- Windows x64 包已进行静态包/依赖检查，尚未 Windows 实机验收。

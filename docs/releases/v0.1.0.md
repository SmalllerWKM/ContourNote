# ContourNote v0.1.0 · 初始人工标注工作台

本地完成/构建日期：2026-11-02。

## 初始功能

- 独立实现本地人工标注，无 AI 模型、权重下载或云端推理。
- 提供多边形、矩形、点、线、涂鸦、圆形、选择编辑、小手平移、缩放及快捷键。
- 支持完整区域与前景/背景弱提示、节点调整、局部重画、当时的补画/合并/扣除、复制粘贴和帧间坐标复用。
- 支持 Labelme JSON 导入和实时保存、草稿恢复、原子写入及上一版 .json.bak。
- 导出 Labelme JSON、COCO、完整语义 Mask、弱提示 Mask 和类别映射。
- 当时包含医生记录、图像判断、审核和质量信息；这些控件后来在 0.5.2 移除。
- 初期 Shift 采点无需按鼠标键，此手势在 0.3.0 改为 Shift＋左键拖动。

## 验证

- 存档验证记录为 31 项通过，包含数据格式及 Qt 交互检查；提供源码启动脚本和合成演示数据。

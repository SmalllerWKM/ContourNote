# ContourNote v0.4.0 · 后台索引、折线切分、闭合撤销与视野吸附

本地完成/构建日期：2026-11-03。

## 新增

- 新增折线切分编辑开关：从已有节点开始，接到原轮廓任意边线；蓝、橙预览选择较大块、较小块或两块，可记住选择。
- 识别与图像外框连通且各 RGB 通道不超过 12 的近黑填充，提供视野边缘吸附开关。

## 优化与修复

- 大于 100 张的项目后台读取 JSON 类别与完成状态，逐批更新；切帧不再重新扫描整个项目。
- 自动闭合后立即撤销可恢复闭合前全部草稿点，再次撤销才逐点回退。
- 取消单路径 5,000 点上限；实际接受的采样点逐点写入 JSON，不做标注轮廓多项式拟合或简化。

## 验证与后续变化

- 61 项测试通过，Mac 独立应用验证通过。
- 合成压力检查包含 30,000 个列表条目、29,999 份空形状 JSON 和首张实际合成图，本机列表/首张加载约 0.166 s；并非 30,000 张实际大图和密集轮廓的完整验收。
- 纯近黑检测被 0.5.0 渐变视野方案替代；切分开关和记住选择也在 0.5.0 移除。

## 发行状态与限制

- macOS Apple 芯片包已进行本机独立应用验证。
- Windows x64 包已进行静态包/依赖检查，尚未 Windows 实机验收。
- 已知跨项目保存目录隔离和跨盘保存问题尚未修复，不应将此版本描述为已完成稳定性验收。

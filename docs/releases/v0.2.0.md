# ContourNote v0.2.0 · 简约界面、自动闭合与文件状态

本地完成/构建日期：2026-11-02。

## 新增与重构

- 重做紧凑浅色工具栏、单色绘图工具与合并侧栏。
- 有效多边形接近起点自动闭合，可设开关及距离。
- 增加独立“打开标注”入口，读取 Labelme JSON 与任意已有类别。
- 增加自动保存开关、手动保存、文件真实修改时间、外部更改监测和重新载入。
- 取消预设前景类别，由用户添加并随项目保存；无操作保存不刷新文件时间。

# 验证记录

本页于 2026-11-06 更新，当前应用版本 1.0.0。各节分别记录当时实际执行的验证，不把历史测试当作重新执行。

## 1.0.0

- 基于 0.6.0 现有功能重新构建，应用内部版本、Mac Info.plist、Windows 构建清单与下载包统一为 1.0.0。
- 本次重新执行 86 项自动化测试全部通过；有 2 条已有 pycocotools / NumPy 弃用警告。
- 2026-11-07：Mac 1.0.0 独立应用原生运行通过，frozen=true、version=1.0.0；JSON 保存、COCO 导出、窗口渲染通过。截图见 [1.0.0 工作台](images/workspace-v1.0.0.png)。
- Windows 重新构建后的 ZIP 完整性、全部应用源码一致性检查通过；78 个 PE/DLL/PYD 静态依赖检查无未解决 DLL，最长包内路径 108 UTF-16 单位；仍未进行 Windows 实机验收。

## 0.6.0

- 86 项自动化测试通过，包含默认大块即时保存、双击小块切换、撤销、无弹窗帧复制、持久化复制来源、范围校验、可见放映控件和 Mac Command/Control 的 C/V/S。
- 自动保存关闭时保留未保存状态，不将复制成功误报为已写入磁盘。
- 新建 contour_note_copy 为复制来源扩展，不恢复历史审核页面或人员记录。
- Mac 0.6.0 独立应用原生启动、JSON 保存、COCO 导出和窗口渲染通过；界面截图见 docs/images/workspace-v0.6.0.png。
- Windows 78 个 PE/DLL/PYD 静态依赖检查无未解决 DLL，包内最长路径 108 UTF-16 单位；尚未 Windows 实机验收。

## 0.5.2 原始记录

- 本地开发环境：macOS，Python 3.12，PySide6 6.12；Qt 自动化使用 offscreen 后端。
- 0.5.2：75 项自动化测试通过，包含关闭提示保留草稿、悬停/拖动不弹窗、点击确认、移除记录控件、新 JSON 无自动 clinical 字段、旧字段保留等。

- Mac 独立应用：原生启动，frozen=true，使用应用内部运行环境；JSON 保存、COCO 导出、窗口渲染通过。
- Windows x64：ZIP 完整性、相对路径不超过 120 UTF-16 单位、归档应用代码一致性检查通过；递归审计 123 个 PE/DLL/PYD，无未解决的非系统 DLL。**尚未 Windows 原生启动/交互验收。**

## 性能结果的适用范围

- 0.4.0：30,000 列表条目、29,999 空形状 JSON 和首张实际合成图片，本机初次列表/首张加载约 0.166 秒。它不是 30,000 张实际大图、密集轮廓、网络盘或医生使用效率测试。
- 0.5.0：1920×1080 合成渐变 PNG，20 次视野检测包含解码和缩略，中位 21.55 ms、95 分位 22.42 ms。它不是所有图像和设备的延迟保证。

当前仍有已知保存问题，见 [KNOWN-ISSUES](KNOWN-ISSUES.md)。测试和打包成功不能推断不存在数据错误，也不能替代临床验证。

# 验证记录

本页于 2026-11-05 整理，当前应用版本 0.5.2。此次整理文档未修改运行代码，也未把历史测试当作重新执行。

## 当前记录

- 本地开发环境：macOS，Python 3.12，PySide6 6.12；Qt 自动化使用 offscreen 后端。
- 0.5.2：75 项自动化测试通过，包含关闭提示保留草稿、悬停/拖动不弹窗、点击确认、移除记录控件、新 JSON 无自动 clinical 字段、旧字段保留等。
- 有 2 条 pycocotools / NumPy 第三方弃用警告。外部 Labelme 对照测试在缺少独立参考仓库时会跳过，因此其他环境的数量可能不同。
- Mac 独立应用：原生启动，frozen=true，使用应用内部运行环境；JSON 保存、COCO 导出、窗口渲染通过。
- Windows x64：ZIP 完整性、相对路径不超过 120 UTF-16 单位、归档应用代码一致性检查通过；递归审计 123 个 PE/DLL/PYD，无未解决的非系统 DLL。**尚未 Windows 原生启动/交互验收。**

## 性能结果的适用范围

- 0.4.0：30,000 列表条目、29,999 空形状 JSON 和首张实际合成图片，本机初次列表/首张加载约 0.166 秒。它不是 30,000 张实际大图、密集轮廓、网络盘或医生使用效率测试。
- 0.5.0：1920×1080 合成渐变 PNG，20 次视野检测包含解码和缩略，中位 21.55 ms、95 分位 22.42 ms。它不是所有图像和设备的延迟保证。

当前仍有已知保存问题，见 [KNOWN-ISSUES](KNOWN-ISSUES.md)。测试和打包成功不能推断不存在数据错误，也不能替代临床验证。

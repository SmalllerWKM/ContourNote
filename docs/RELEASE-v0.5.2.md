# 临绘 0.5.2：手动确认重画、可关闭提示、移除记录页面

## 提示可关闭

画布上方的黄色提示条增加“关闭提示”按钮。关闭只隐藏文字，不会删除当前草稿。成功完成或取消草稿时也会清除提示。后续发生新的错误时才重新显示相应说明。

## 点击原边界才确认重画

双击已有多边形节点或边线开始重画。移动鼠标接近、经过原边界，以及 Shift＋左键拖动经过原边界，都不会弹出保留区域对话框。

当确定新边界终点时，在原轮廓边线上单击左键，才闭合候选区域并弹出蓝色/橙色保留选择；右键点击原边界也可确认。保留少量屏幕点击容差便于命中边线，不再将距离检测用于鼠标移动时的自动确认。

新建多边形的接近起点自动闭合、右键和 Enter 完成仍保留；此次只改变已有轮廓重画的结束触发方式。

## 删除记录功能

删除右侧“记录”页和图像判断、置信度、审核状态、画面质量、识别困难、备注等编辑控件。新增、复制与传播标注不再自动写入有目标/无目标、审核状态和传播来源等记录字段。

新项目 JSON 不再生成 clinical 记录字段。旧标注里已有的 clinical 扩展按原内容保留，几何编辑和保存不会清空历史数据。旧字段仅原样透传，不再参与当前校验或 Mask 判定。没有完整区域的图仍输出未知值 255，旧 clinical 中“无目标”也不再自动产生全背景 Mask，避免不可编辑的旧记录控制当前结果。完成勾选以形状或 Labelme flags 判断，不再以旧临床记录作为完成条件。

## 验证

新增用例覆盖：移动/Shift 拖动不弹窗而点击边界弹窗；关闭提示保留草稿；没有记录界面；新 JSON 没有自动记录字段；旧文件记录保持不变。此前的视野约束、闭合、编辑、格式和保存测试继续执行。

Mac 提供独立 Apple 芯片应用；Windows x64 提供短路径 CN 便携包，Windows 尚未实机验收。此前审查发现的跨项目保存目录和跨盘保存问题仍未在此版本修复。
